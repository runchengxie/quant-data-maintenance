# Maintenance model

The tools separate observation from mutation.

`audit` only creates reports and never removes or rewrites data. It tracks device/inode metadata, caches stable hashes, compares sampled content before full hashing, and performs a final inventory check. A report with `stable: false` requires investigation.

`consolidate` first identifies manifest-identical `.npy` files in validation, OOS, and monitoring partitions. The default command prints a plan. Applying a plan requires `--apply --writers-stopped`, obtains a maintenance lock, checks open descriptors and mappings, keeps a journal, creates read-only shared content, replaces verified duplicates with relative symlinks, and verifies every replacement.

Restoration requires the receipt generated by an apply operation and `--restore --writers-stopped`. Shared content remains retained after restoration so recovery does not silently discard evidence.
